## 新增

- 后台任务可以注册成可重放的任务：注册后能再次启动、重启、停止和删除，命令、工作目录和解释器都由 host 原样保存，随会话一起移动和归档。
- 模型可以直接操作已注册任务：列出、启动、重启、停止，一律按命令 id 定位；重启在 job 已丢失重启配方时改用注册定义先停后起，跨会话重开也不再失效。

## 变更

- 注册任务不再要求选择「服务 / 一次性」：两种类型行为一致，重启一律可用，能否原地接管进程树由 host 自己决定。已注册行的类型标签随之移除。
- 已注册行新增删除控件，位于启动按钮旁，需要确认一次；运行中的任务拒绝删除，要求先停止。

## 修复

- 后台任务的开始与结束现在会让界面重读状态快照，因此在配对的另一台设备上启动的任务会立即出现在当前窗口。
- `register_task_command` 与 `task_command` 此前不在 provider 可见名单里，模型看不到也调用不到，现在可用；两者对子代理仍然不可见。
- 损坏的任务注册表不再阻止会话移动，文件中未知字段在保存时保留。
